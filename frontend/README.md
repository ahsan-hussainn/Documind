# DocuMind — Frontend

React + TypeScript + Tailwind CSS chat interface for DocuMind.

See the [root README](../README.md) for full project documentation.

## Dev

```bash
npm install
npm run dev
```

Runs on `http://localhost:5173` by default. Expects the API at `http://localhost:8000` (configurable via `VITE_API_URL` env var).
